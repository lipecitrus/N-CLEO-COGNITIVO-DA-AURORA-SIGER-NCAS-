🪐 Núcleo Cognitivo da Aurora Siger (NCAS)

Sistema desenvolvido em Python para registrar, organizar, consultar e interpretar informações operacionais da colônia Aurora Siger, utilizando arquivos .txt, .json, regras de lógica booleana e prompts estruturados.

O projeto aplica conceitos de manipulação de arquivos, estruturas de dados, álgebra booleana, lógica de decisão, engenharia de prompts e simulação de IA generativa, demonstrando como essas tecnologias podem ser utilizadas no gerenciamento de uma colônia em Marte.

🚀 Principais funcionalidades
Cadastro e consulta de registros da colônia;
Leitura e gravação de arquivos .txt;
Leitura e escrita de dados em .json;
Validação de informações por meio de regras lógicas;
Simplificação de expressões booleanas;
Prompts estruturados para análise de informações;
Simulação de respostas de um assistente inteligente;
Menu interativo executado pelo terminal.
🛠️ Tecnologias

Python • JSON • TXT • Lógica Booleana • Prompt Engineering • IA Generativa

Projeto acadêmico desenvolvido como parte da Atividade Integradora – Núcleo Cognitivo da Aurora Siger (NCAS).
